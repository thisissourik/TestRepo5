PROGRAM 6 
----------

open web browser
go to localhost:8080

create new job > new item > Enter item name 'maven-ci' > select freestyle > OK
Configure SCM : Select Git > Enter repo details 

Add maven build step 

Scroll down to build and click on add build step
Select Invoke top level maven targets
In goal field : clean package

Pom : myapp/pom.xml

Save > Build Now > Build success


CI Pipeline

New item > Pipeline script >
Enter script

pipeline {
    agent any

    stages {
        stage('Checkout') {
            steps {
                git branch: 'main', url: 'https://github.com/suyash3312/JENKINS.git'
            }
        }

        stage('Build') {
    steps {
        dir('myapp01') {
            bat 'mvn clean package'
        }
    }
}

stage('Test') {
    steps {
        dir('myapp01') {
            bat 'mvn test'
        }
    }
}
    }

    post {
        always {
            junit '**/target/surefire-reports/*.xml'
        }

        success {
            echo 'Build and tests succeeded!'
        }

        failure {
            echo 'Build or tests failed.'
        }
    }
}

Save

Trigger build by clicking Build Now
Verify and confirm
